## A. 安装与启动

- [ ] 自包含 exe 可启动（管理员）
- [ ] 单实例：二次启动激活已有窗口
- [ ] 托盘图标显示；双击恢复窗口
- [ ] 隐藏到托盘后再打开正常

## B. 连接与布局

- [ ] 两台 Win 相同安全密钥，双向「双向已连接」
- [ ] 局域网发现可见对端并可添加
- [ ] 1×4 / 2×2 布局切换并「应用」，对端同步
- [ ] 拖拽互换槽位；移除后再从发现添加
- [ ] 断网 / 关对端后重连成功

## C. 键鼠

- [ ] 轻松鼠标：移出边缘切换
- [ ] 环形鼠标开/关符合预期
- [ ] 四角阻挡开/关符合预期
- [ ] 热键切换机器（F1–F4 或 1–4）
- [ ] Ctrl+Alt+M 打开设置；Ctrl+Alt+R 重连抽样

## D. 剪贴板与文件

- [ ] 文本复制 → 移到对端可粘贴
- [ ] 截图 / 图片可同步（按现网行为）
- [ ] 文件复制 → 移到对端后台接收 → 可粘贴；接收中键鼠不卡死
- [ ] 直接传输到桌面 / 文档 / 自定义路径
- [ ] 「清除已完成」只清接收缓存，不删发送方源文件

## E. 设置与系统

- [ ] 淡色 / 深色主题切换并应用
- [ ] 语言切换后主要 UI 文案更新（抽样）
- [ ] 网卡选择与刷新
- [ ] 开机自启开关（抽样，需管理员）

## F. 更新与诊断

- [ ] 帮助 → 检查更新不崩溃
- [ ] 一键检查有输出
- [ ] （若本版含更新逻辑变更）替换日志与重启抽样

## G. 兼容

- [ ] 本版 ↔ 上一 stable 交叉连接（键鼠 + 文本剪贴板至少）
