## A. 安装与启动

- [ ✔ ] 自包含 exe 可启动（管理员）
- [ ✔ ] 单实例：二次启动激活已有窗口
- [ ✔ ] 托盘图标显示；双击恢复窗口
- [ ✔ ] 隐藏到托盘后再打开正常

## B. 连接与布局

- [ ✔ ] 两台 Win 相同安全密钥，双向「双向已连接」
- [ ✔ ] 局域网发现可见对端并可添加
- [ ] 1×4 / 2×2 布局切换并「应用」，对端同步
- [ ] 拖拽互换槽位；移除后再从发现添加
- [ ] 断网 / 关对端后重连成功

## C. 键鼠

- [ ] 轻松鼠标：移出边缘切换
- [ ] **稳住对端**：从本机切入对端后，在对端持续操作一段时间，光标不应无故跳回本机（须先移入内侧再从进入边推回）
- [ ] 环形鼠标开/关符合预期
- [ ] 四角阻挡开/关符合预期
- [ ] 穿边模式：无障碍 / 双击 / 极速切换后说明文案更新，点「应用」后对端同步
- [ ] 热键切换机器（F1–F4 或 1–4）
- [ ] Ctrl+Alt+M 打开设置；Ctrl+Alt+R 重连抽样

## D. 剪贴板与文件

（格式细表见 [clipboard.md](../clipboard.md)。Win ↔ Maui-Win 为必测主路径。）

- [ ] 文本复制 → 移到对端可粘贴（双向：Win↔Win、Win↔Maui-Win）
- [ ] HTML / RTF / CSV（如 Word、Excel）→ 对端粘贴仍为对应格式（Maui-Win 抽测）
- [ ] 截图 / 图片双向可同步并可 Ctrl+V
- [ ] 文件复制 → 移到对端 → 虚拟剪贴板可粘贴；接收中键鼠不卡死
- [ ] 文件夹复制粘贴（抽样）
- [ ] 直接传输到桌面 / 文档 / 自定义路径
- [ ] 共享传输列表列完整（方向/文件名/对端/大小/进度/状态/删除）
- [ ] 「打开收件箱」能打开本机 Inbox 目录
- [ ] 「清除已完成」只清接收缓存，不删发送方源文件

## G. 兼容

- [ ] 新端 ↔ 新端：连接状态含 `Platform`/`Caps` 摘要（或日志等价信息）

## H. Caps 门控（W0+）

- [ ] 对端 Caps **无** `EdgeMouse` 时：布局中不因边缘切换切到该对端
- [ ] 对端为 MAUI Android（Caps 含 `EdgeMouse`+`InjectInput`）且已开无障碍：边缘可切入；点击/滑动可用
- [ ] 手机触控板：滑动移光标；轻点=左键；中区轻点=中键；系统键盘输入出现在本机（AbsPointer / SwitchFocus）
- [ ] `dotnet test tests/FlyScreen.Core.Tests` 通过（握手 / Caps 交集；`AndroidMobile` 含 EdgeMouse/Inject、无 LayoutSync）
