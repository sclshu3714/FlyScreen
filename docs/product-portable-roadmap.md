## 0. 结论

**“便携”不是在包里多塞一个便携屏或 KVM，而是让已有的 2–4 台设备在没有路由器、没有管理员、网络随时变化的情况下，60 秒内组成一个能干活的工作站。**

这条线真正成立的是 **6 个能力层**：

1. **随身连接**：不依赖路由器/同网段/管理员，手机热点、USB 共享、蓝牙、Wi-Fi Direct 都能连；换网自动重连。
2. **随身角色**：笔记本当主机，平板当第二屏/笔屏，手机当键盘/触控/摄像头/麦克风；一键切换，记住每台设备的角色。
3. **随身工作台**：把正在做的工作打包，到另一台设备本地展开；不是远程看画面。
4. **随身电力**：手机当摄像头/热点会耗电，平板当屏会耗电；按电量分配角色，低电自动降级。
5. **随身安全与离线**：酒店/咖啡厅/客户网络不可信；不暴露端口、不依赖云、没有互联网也能连。
6. **随身笔/屏**：平板作为压感笔屏，补上“手写/绘画/批注”这一种现有投屏没有的输入。

**不建议为了凑 11 个版本号硬拆。** 这 6 层之后，剩下的多是场景包、验证或未来探索；硬占新功能版本号会注水。文末给了“如果必须排到 1.1.10”的扩展位，但标注了不建议。

## 1. “便携”到底指什么

一个人，2–4 台设备，典型组合：

- Windows 笔记本（主机/算力）
- Android 手机（网络、键盘/触控、摄像头、麦克风、热点）
- Android/iPad 平板（第二屏、笔屏、批注）
- 偶尔第二台笔记本或迷你主机（算力/存储）

典型环境：

- 家里：有路由器，但不想配静态 IP/防火墙。
- 咖啡厅：公共 Wi-Fi，客户端隔离，不能互访。
- 酒店： captive portal，登录后换网，设备互相看不到。
- 客户现场：没有管理员权限，不能装驱动/改防火墙。
- 火车/机场：没有路由器，只有手机热点或 USB 共享。
- 临时借用别人的电脑：不能安装、不能留痕。

**核心约束：不能要求“同一个网段”、不能要求“管理员权限”、不能要求“登录账号”、不能要求“上云”。**

## 2. 五个真实痛点

| # | 痛点 | 现在怎么解决 | 为什么不够 |
|---|------|--------------|------------|
| 1 | 设备连不上：酒店 Wi-Fi 隔离、客户网络、没有路由器、IP 变化、休眠断连 | 手机热点、USB 共享、手动 IP、远程桌面、Tailscale | 热点/USB 共享只能上网，不组成设备间工作网；Tailscale 要账号/装客户端；远程桌面要公网/账号 |
| 2 | 每台设备角色不固定：平板当屏、手机当键盘/摄像头、笔记本当主机，每次重配 | 投影、共享设备、手机触控板、第三方第二屏 App | 每个能力是单独入口，没有“这次出门，三台设备各做什么”的一键编排；角色冲突/回退不管 |
| 3 | 工作现场搬不走：咖啡厅做到一半，到酒店要重开文件/网页/窗口 | 网盘、浏览器同步、远程桌面、手动重开 | 网盘只同步文件，浏览器只同步标签，远程桌面是远程看/控；没有“本地重建工作现场” |
| 4 | 电力撑不住：手机当摄像头/热点、平板当屏，半天就没电 | 充电宝、降低亮度、少用 | 没有跨设备电量策略：谁该降级、谁该停、充电先充谁 |
| 5 | 公共网络不敢用：酒店/客户 Wi-Fi 不可信，不想开端口、不想上云 | 不开共享、用完就关、VPN | 现有工具默认“可信局域网”；没有“公共网络模式”：不广播、不开端口、临时信任、用完即清 |

## 3. 现有方案为什么不够

| 方案 | 能做什么 | 缺口 |
|------|----------|------|
| Apple 连续互通 | Apple 设备间接力、第二屏、剪贴板 | 只 Apple；要同账号；跨品牌不行 |
| 三星/华为/小米多设备协同 | 同品牌手机+PC/平板协同 | 绑定生态；跨品牌不行 |
| Phone Link | Windows + Android 通知/文件/手机屏 | 要微软账号；机型/功能受限；不是设备编排 |
| Synergy / Barrier / Deskflow | 局域网键鼠共享 | 要同网段/管理员；桌面为主；不管手机/平板角色 |
| scrcpy | USB/ADB 控制手机 | 要开发者选项/ADB；不是便携组网 |
| Spacedesk 等第二屏 | 平板当扩展屏 | 只做屏；不管输入/电力/安全 |
| Tailscale / ZeroTier | 跨网组网 | 要账号/装客户端；不是设备角色编排 |
| 便携屏/便携键盘/ KVM 小盒子 | 硬件替代 | 增加重量/体积/线缆；不能解决网络与角色 |
| LocalSend | 近距离传文件 | 只传文件；不管角色/工作台/电力 |

**空位：跨品牌、无账号、无云、无管理员、2–4 台设备、把“连接 + 角色 + 工作台 + 电力 + 安全”合成一个便携模式。** 这正是 FlyScreen 已经有地基、但还没做成产品的地方。

---

## 4. 产品独特资产

1. **已经在每台设备上**：连接、输入注入、剪贴板、文件、投影、Android 无障碍/MediaProjection 都已存在。
2. **本地、无云、开源**：对公共网络/隐私敏感的用户，是差异化。
3. **2–4 台设备的布局与角色**：已有布局/设备管理，可以扩展成“便携角色编排”。
4. **工具/脚本系统**：可以把角色、场景、规则做成可扩展的内容，而不是每次写死。

## 6. 各版详情

### 6.1 v1.1.0 随身连接

**新增什么**：一个“无路由器组网”层。

- 配对：二维码/6 位码，内含端点 + 临时密钥；不依赖广播/同网段。
- 路径：手机热点、USB 共享（RNDIS）、蓝牙 PAN、Wi-Fi Direct；手动地址兜底。
- 换网：网络变化检测、自动重连、休眠/唤醒、 captive portal 识别。
- 安全：加密、临时会话、默认只开一个端口、不依赖云。
- 权限：优先用户态；必须提权时明确提示，不静默要求管理员。

**场景**：

- 酒店 Wi-Fi 开启客户端隔离，两台设备互相看不到 → 用手机热点或 USB 共享直连。
- 客户现场没有管理员权限 → 不装服务、不改防火墙，用用户态 + 二维码连。
- 火车上没有路由器 → 手机热点/USB 共享，笔记本 + 平板组网。
- 咖啡厅换网 → 自动重连，不用重新配对。

**为什么不是现有功能**：这是新的**网络可达层**，不是给现有连接加一个“手动 IP”输入框；它要解决“不同网络路径下的可达与重连”。

**为什么通用工具替代不了**：Synergy/Barrier 要同网段/管理员；scrcpy 要 ADB；Phone Link 要账号；Tailscale 要账号/客户端。没有“跨品牌、无账号、无管理员、按场景选路径”的便携连接层。

**依赖**：现有连接/发现/协议；需要新增路径选择与会话恢复，但不能破坏现有 LAN 主路径。

**门禁**：在家、咖啡厅、酒店、客户现场、火车 5 类环境各试 3 次；首次连接中位 <90 秒、换网重连 <30 秒、无需管理员；任一不达标就停，不进入角色层。

---

### 6.2 v1.1.1 随身角色

**新增什么**：一个“这次出门，每台设备做什么”的编排层。

- 角色：主机/算力、第二屏、笔屏、键盘/触控、摄像头、麦克风、扬声器、存储。
- 一键配置：选一个“便携组合”，自动分配角色、布局、连接路径。
- 记忆：每台设备记住上次角色；换场景只改差异。
- 冲突/回退：同一设备不能同时当屏和摄像头；角色失败时给出替代（如手机摄像头不可用 → 用平板）。
- 电量感知的默认角色（与 v1.1.3 联动）。

**场景**：

- 笔记本主机 + 平板第二屏 + 手机键盘/触控：咖啡厅写作。
- 笔记本主机 + 手机摄像头/麦克风 + 平板批注：客户演示/会议。
- 笔记本主机 + 平板笔屏：火车上画草图/批注。
- 第二台笔记本当第二屏/算力：酒店里双机。

**为什么不是现有功能**：现有共享设备/投影/手机触控板是**单点能力**；这一版是**角色编排**：一次选择，多个角色一起生效，失败有替代，换场景只改差异。

**为什么通用工具替代不了**：Spacedesk 只做屏；手机触控板 App 只做输入；共享摄像头是单独工具；没有“一个人出门，三台设备角色一键编排”的产品。

**依赖**：v1.1.0 连接；现有输入/投影/共享设备能力作为角色实现。

**门禁**：连续 2 周每次出门设置 <2 分钟；角色切换不用重新配对；至少 3 种组合真实用过；否则停。

---

### 6.3 v1.1.2 随身工作台

**新增什么**：打包/展开工作现场。

- 打包：当前打开的文件、URL、前台应用、窗口位置、当前目录、剪贴板（可选）、角色配置。
- 展开：到另一台设备本地打开文件/URL/应用，恢复窗口位置与角色；失败项列出，可重试/跳过。
- 场景模板：咖啡厅→酒店、客户演示、火车继续写。
- 干净断开：打包后可选关闭/保留源端，避免两边同时改同一文件。

**场景**：

- 咖啡厅做到一半 → 打包 → 到酒店展开，IDE/文档/网页都在。
- 客户现场演示 → 展开“演示工作台”，PPT/浏览器/投屏布局就位。
- 火车上继续写 → 展开到平板/笔记本。

**为什么不是现有功能**：这是**工作现场状态层**，不是远程桌面/投屏；接收端是本地打开，不是远程画面。

**为什么通用工具替代不了**：网盘只同步文件；浏览器同步只同步标签；远程桌面是远程操作；Handoff 只覆盖少量应用；没有跨品牌/跨 4 台/带角色与布局的工作台。

**依赖**：v1.1.1 角色；现有文件/剪贴板通道；窗口枚举（Windows 先做）。

**门禁**：每次出门至少 1 次打包/展开；恢复成功 >80%；否则说明 manifest 覆盖不够，先补能力，不继续。

---

### 6.4 v1.1.3 随身电力

**新增什么**：跨设备电量策略。

- 电量预算：每个角色估算耗电；出门前给出“这套组合能撑多久”。
- 低电降级：手机 <20% 停摄像头/热点；平板低电降亮度/降帧；笔记本低电暂停非必要投影。
- 充电顺序：先保主机/网络，再保屏/外设；多口充电器分配建议。
- 热/休眠：休眠前保存角色与工作台；唤醒后恢复；热降频时降帧而不是断连。

**场景**：

- 手机当摄像头 + 热点，2 小时后电量告急 → 自动停摄像头，保留网络。
- 平板当第二屏，半天就没电 → 低电降亮度/帧率，或改用笔记本单屏。
- 酒店只有一个插座 → 给出充电顺序，先保第二天要用的设备。

**为什么不是现有功能**：这是**跨设备电力策略层**，不是给投影加一个“省电模式”开关；它要知道每个角色耗多少、谁该降级。

**为什么通用工具替代不了**：系统省电模式只管单机；充电宝只管供电；没有“角色级电量预算与降级”的产品。

**依赖**：v1.1.1 角色；电量/热/休眠状态采集。

**门禁**：同一套组合，开启策略后续航有可测量提升；不出现“策略导致断连/意外关机”；否则停。

---

### 6.5 v1.1.4 随身安全与离线

**新增什么**：公共网络/无网模式。

- 公共网络模式：不在 LAN 广播、不开额外端口、不响应陌生扫描；只保留已配对会话。
- 临时信任：一次会话、到期自动失效；设备借用/丢失可撤销。
- 每网络档案：家里/公司/酒店/客户，不同信任级别与默认角色。
- 离线模式：没有互联网也能通过二维码/蓝牙/直连组网；不依赖云。
- 借用模式：在不能安装的电脑上用便携方式临时加入，退出即清理（如果实现成本可控，可并入本版或后续）。

**场景**：

- 酒店/咖啡厅公共 Wi-Fi：不暴露共享，不广播设备名；只用已配对加密会话。
- 客户现场：临时信任一台设备，会议结束自动失效。
- 没有互联网：手机热点没信号/飞行模式，仍能本地组网传文件/投屏。
- 借用同事电脑：不安装、不留痕，临时加入。

**为什么不是现有功能**：这是**信任/网络边界层**，不是给现有连接加一个“密码”；它要处理公共网络、临时信任、离线、借用四种边界。

**为什么通用工具替代不了**：Synergy 默认可信 LAN；Tailscale 要账号/云；远程桌面要公网；LocalSend 只传文件；没有“公共网络不暴露 + 离线 + 临时借用”的便携边界。

**依赖**：v1.1.0 连接；设备身份/会话密钥；现有信任模型。

**门禁**：公共 Wi-Fi 下用端口扫描/陌生设备视角确认不暴露；离线模式可完成一次文件+一次投屏；否则停。

### 6.6 v1.1.5 场景包与装备建议（内容层，不单独算能力版）

**新增什么**：

- 场景包：咖啡厅、酒店、客户现场、火车、家里；每包预置连接路径、角色、布局、电力策略、安全级别。
- 装备建议：根据场景和角色，提示“带什么/不带什么”：平板能否替代便携屏、手机能否替代摄像头/麦克风、是否需要带 USB-C 线/小 Hub/充电宝。
- 出发清单：一次性勾选，减少“到现场发现少带一根线”。

**场景**：

- 明天去客户现场：建议“笔记本 + 平板 + 手机 + USB-C 线 + 小 Hub”，不带便携屏。
- 酒店办公：建议“手机热点 + 平板第二屏 + 手机摄像头”，带一个多口充电器。
- 火车：建议“笔记本 + 平板笔屏 + 充电宝”，不带鼠标。

**为什么不是现有功能**：这是**场景内容/决策层**，把前五个能力组合成“出门就用”的包；不是新代码能力。

**门禁**：每次出门至少用 1 个场景包；装备建议真的改变了你带的东西；否则说明场景包是摆设，停。

---

### 6.7 v1.1.6 随身笔/屏

**新增什么**：平板作为**压感/倾斜笔屏**，不是普通第二屏。

- 压感级别、倾斜、掌托拒绝、笔按钮、Windows Ink 兼容。
- 便携优化：低延迟、低电量、断线恢复；优先 USB-C/热点直连。
- 场景：客户现场画草图/批注、火车上画线框、酒店里手写签名。

**为什么不是现有功能**：现有投影 + 回控只有位置/点击，没有压感/倾斜/掌托；这是新的**笔输入设备角色**。

**为什么通用工具替代不了**：Wacom/SuperDisplay 是独立硬件/软件；FlyScreen 的差异是复用已配对设备、便携角色、无需再装一套投屏。

**依赖**：H.264/E2 编码、帧率/分辨率协商、平板笔事件采集、Windows Ink 注入。

**门禁**：端到端延迟 <50ms、压感 ≥1024 级、掌托误触可接受；任一不达标就不发。**技术风险最高，放在最后。**

## 7. 便携方式：设备、连接、角色、电力、携带清单

### 7.1 推荐的“一人三设备”组合

| 设备 | 角色 | 说明 |
|------|------|------|
| 笔记本 | 主机/算力/主屏 | 跑 IDE、浏览器、文档；有键盘/触控板 |
| 平板 | 第二屏/笔屏/批注 | 替代便携屏；有笔时做批注/绘画 |
| 手机 | 网络/键盘/触控/摄像头/麦克风/扬声器 | 热点或 USB 共享；临时输入/拍摄 |
| 可选：第二台笔记本/迷你主机 | 第二屏/算力/存储 | 酒店/客户现场需要双机时 |

### 7.2 连接路径优先级

1. **USB-C 数据线直连**：最稳、最低延迟、可同时供电；适合笔记本↔平板/手机。
2. **手机热点（5GHz）**：没有路由器时最通用；注意客户端隔离和电量。
3. **USB 共享（RNDIS）**：手机用 USB 给笔记本供网；比热点省电、稳定。
4. **蓝牙 PAN**：低速兜底，适合文字/剪贴板，不适合投屏。
5. **Wi-Fi Direct**：无路由器直连；跨平台兼容性一般，作为备选。
6. **手动地址/二维码**：所有路径失败时兜底。

### 7.3 携带清单（按场景裁剪）

- 必带：笔记本、手机、USB-C 数据线（支持数据+充电）、多口充电器/充电宝。
- 看情况：平板（替代便携屏/笔屏）、平板笔、小 Hub（HDMI/USB-A/网口）、手机支架、平板支架。
- 可以不带：便携屏（平板能替代时）、独立摄像头/麦克风（手机能替代时）、KVM 小盒子（软件直连时）、额外鼠标（手机/触控板能替代时）。

**原则：软件能替代的硬件就不带；带了的硬件要能被角色编排识别。**

## 8. 节奏与门禁

1. **串行**：v1.1.0 连接不过，不做角色；角色不过，不做工作台。
2. **每版 2–6 周**：连接/安全 4–6 周，角色/工作台 3–4 周，电力 2–3 周，笔屏 6 周+。
3. **每版独立回退**：新层默认关闭，不影响现有 LAN 主路径。
4. **门禁是“自己出门用”**：不是办公室坐着测；必须在家、咖啡厅、酒店、客户现场、火车里各试。
5. **允许停**：任何一版门禁不过，直接停这条线，不为了版本号硬发。

## 10. 排除项

- 不把“剪贴板历史、通知中枢、访客互传、手机窗口化、跨设备文件搜索”重新包装成便携功能：它们要么已被现有跨屏粘贴/投影回控/飞书/系统搜索覆盖，要么成本收益不成立。
- 不把 Mac/Linux 键鼠补齐、H.264/E2、UI 打磨写进这条便携新能力路线：它们属于工程/维护，不占新功能版本。
- 不用 Star/Issue/外部用户数做需求证据。

## 11. 需要你拍板

1. **先做 v1.1.0 随身连接，还是先做 v1.1.1 随身角色？** 我建议先连接：连不上，角色编排没有意义；但如果你现在最痛的是“每次出门重配角色”，也可以先角色、连接用现有热点/USB 兜底。
2. **是否接受“只做 6 个能力版，不硬凑 11 个”？** 如果你要 1.1.0–1.1.10 的完整编号，我建议 7–10 作为场景包/验证，不当作新功能版本。
3. **是否接受 Windows 先行？** 连接/角色/工作台先 Windows + Android；Mac/iPad 在各自能力稳定后补，不追求 6 版全平台同步。
4. **你真实出门的组合是什么？** 笔记本+手机、笔记本+平板+手机，还是双笔记本？这决定 v1.1.1 的角色优先级。
