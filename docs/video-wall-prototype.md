# 视频墙：原型规划（界面 / 交互 / 数据）

| 项 | 内容 |
|----|------|
| 性质 | 原型规划（线框 + 交互规格 + 数据模型），不含像素级视觉稿 |
| 日期 | 2026-11-13 |
| 配套 | 需求见 [video-wall.md](video-wall.md)；内核与性能见 [video-wall-feasibility.md](video-wall-feasibility.md) |
| 原型载体 | 不做 Figma。P0 直接在 `Ui.Win`（WPF）里出可点击线框，`Ui.Desktop`（Avalonia）跟随同构；线框阶段允许视觉粗糙 |

---

## 0. 一句话结论

**一个工作区页签，三块区域：左边「源」，中间「墙」，右边「属性」；底部一条全局控制条。**
不做独立主窗、不做多窗口浮动播放器（除「单格全屏」这种临时态），不做视频面内叠加控件（受 airspace 限制，见 [video-wall-feasibility.md](video-wall-feasibility.md) §4）。

## 1. 信息架构

```text
工具页（宿主）
└─ 页签：视频墙
   ├─ 顶部工具条        [＋添加源] [NVR 批量] [发现设备(P1)] [场景 ▾] [布局 1×1|2×2|3×3|4×4] [合流] [全屏]
   ├─ 左栏：源
   │   ├─ 固定源（分组树：全部 / 摄像头 / NVR / 网络地址 / 本机文件）
   │   └─ 临时源（地址输入框 + 最近 20 条）
   ├─ 中间：墙（1/4/9/16 格）
   │   └─ 每格：[标题行] [画面] [底部信息条]
   └─ 右栏：属性（选中源/选中格）
       ├─ 基本信息：名称、类型、地址（脱敏）、协议、编码、分辨率、帧率
       ├─ 传输：码率、缓冲、丢帧、首帧耗时、重连次数
       └─ 操作：编辑、测试、重新连接、复制地址、收藏为固定源（临时源时）
```

折叠规则：窗口宽度 < 1100px 时右栏收起为抽屉（点格右上「i」打开）；< 900px 时左栏可收起（图标按钮）。

## 2. 线框

### 2.1 工作区主视图（3×3，运行中）

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ 视频墙   [＋添加源] [NVR 批量] [场景 ▾]   布局 [1×1][2×2][3×3][4×4]  [合流] [⛶] │
├───────────────┬───────────────────────────────────────────────┬───────────────┤
│ 源             │ ┌───────────┬───────────┬───────────┐         │ 属性           │
│ ▸ 固定源 (12)  │ │ 前台-01   ●│ 走廊-02  ●│ 仓库-03  ●│         │ 名称  前台-01  │
│   摄像头 (6)   │ │ ┌───────┐ │ ┌───────┐ │ ┌───────┐ │         │ 协议  RTSP     │
│    NVR (3)     │ │ │       │ │ │       │ │ │       │ │         │ 编码  H.264    │

│ ▸ 临时源       │ │ └───────┘ │ └───────┘ │ └───────┘ │         │ 帧率  25       │
│   [rtsp://…  ] │ │ 4.2Mbps   │ 3.8Mbps  │ 重连 2/5  │         │ 码率  4.2Mbps  │
│   最近：       │ ├───────────┼───────────┼───────────┤         │ 缓冲  620ms    │
│   • rtsp://…   │ │ 大厅-04  ●│ 门口-05 ⚠│ 车位-06  ●│         │ 丢帧  12       │
│   • http…m3u8  │ │ ┌───────┐ │ ┌───────┐ │ ┌───────┐ │         │ 首帧  1.2s     │
│   • D:\a.mp4   │ │ │       │ │ │ 重连中 │ │ │       │ │         │               │
│                │ │ └───────┘ │ └───────┘ │ └───────┘ │         │ [重新连接]     │
│                │ ├───────────┼───────────┼───────────┤         │ [复制地址]     │
│                │ │ 教室-07  ●│ 空槽 +    │ 空槽 +    │         │ [编辑]         │
│                │ └───────────┴───────────┴───────────┘         │               │
├───────────────┴───────────────────────────────────────────────┴───────────────┤
│ ● 7/9 在线 · 28.4Mbps · CPU 34% · GPU 41% · 丢帧 0.8%   [全部暂停] [全部静音] │
└───────────────────────────────────────────────────────────────────────────────┘
```

要点：

- **视频面内不放控件**（airspace）。标题行在画面**上方**，信息条在画面**下方**；角标（`● / ⚠ / ✕`）也放标题行右侧，不压画面。
- 空格显示「＋」与虚线边框，双击空格可打开「添加源」。
- 每格标题行右侧：状态点 + 静音 + `⋯`（全屏/重连/关闭/属性）。
- 悬停格：标题行与信息条高亮，不改变画面尺寸（避免抖动）。

### 2.2 单格全屏（临时态）

```text
┌───────────────────────────────────────────────────────────────┐
│ 前台-01   ● 4.2Mbps  1920×1080     [静音] [退出全屏(Esc)]     │
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                        画面                                   │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

- `Esc` 退出；`←/→` 切到上一/下一格；空格键在本格暂停/继续（若后端支持）。
- 全屏只放大该格的**呈现区域**，不重建连接（呼应 [video-wall.md](video-wall.md) §3.4「布局切换不断流」）。

### 2.3 合流视图

```text
┌───────────────────────────────────────────────────────────────┐
│ 合流 · 3×3          音频 [静音 ▾]   [全屏] [输出(P2)] [返回墙] │
├───────────────────────────────────────────────────────────────┤
│  ┌───────────┬───────────┬───────────┐                        │
│  │   前台    │   走廊    │   仓库    │                        │
│  ├───────────┼───────────┼───────────┤                        │
│  │   大厅    │   门口    │   车位    │                        │
│  ├───────────┼───────────┼───────────┤                        │
│  │   教室    │  空槽     │  空槽     │                        │
│  └───────────┴───────────┴───────────┘                        │
└───────────────────────────────────────────────────────────────┘
```

- 合流视图是**另一个页面级视图**（不是弹窗），返回键回墙；合流期间墙上各格仍在播放（同一批播放器，只是渲染目标切换）。
- 默认不画标题与状态（纯净画面）；开关「显示标注」时以半透明底条显示名称。
- 音频策略：`静音`（默认）/ `独奏：<某格>` / `混音(P2)`。

### 2.4 添加 / 编辑固定源（对话框）

```text
┌─ 添加视频源 ─────────────────────────────────────┐
│ 类型   (•) 网络地址  ( ) 本机文件  ( ) 摄像头     │
│ 名称   [ 前台-01                        ]        │
│ 地址   [ rtsp://192.168.1.64:554/Streaming/…  ]  │
│ 认证   [ 无 ▾ ]  [用户名] [密码]                  │
│ 高级   ▾ 自定义 Header / 传输(TCP·UDP) / 缓冲 800ms│
│ 分组   [ 摄像头 ▾ ]                              │
│ 解码   [ 自动（优先硬解） ▾ ]                     │
│                                                  │
│ 测试结果：● 已连接 · H.264 · 1920×1080 · 25fps   │
│                        [测试]  [取消]  [保存并播放]│
└──────────────────────────────────────────────────┘
```

规则：

- 「测试」不落盘、不建播放器会话，只做协议探测 + 取首帧信息（≤3s 超时）。
- 保存后可选「立即播放到空格」。
- 密码框在编辑时不回显明文，显示为「已保存」+「修改」按钮。

### 2.5 NVR 批量导入（对话框）

```text
┌─ 从 NVR 批量添加 ───────────────────────────────────────┐
│ 主机 [192.168.1.100] 端口 [554]  认证 [admin] [****]    │
│ 主码流模板 [ rtsp://{host}:{port}/Streaming/Channels/{ch}01 ] │
│ 子码流模板 [ rtsp://{host}:{port}/Streaming/Channels/{ch}02 ] │
│ 通道范围 [1] – [16]   命名前缀 [ 通道- ]  使用 (•)主码流 ( )子码流 │
│                                                          │
│ 预览：                                                   │
│  ☑ 通道-01  rtsp://…/101  ☑ 通道-02  rtsp://…/201  …    │
│                                                          │
│  [全部测试(并发 4)]           [取消]  [添加选中的 16 路] │
└──────────────────────────────────────────────────────────┘
```

规则：测试并发上限 4（避免把 NVR 打挂）；失败项标红但不阻断添加；模板必须支持 `{host}` `{port}` `{user}` `{ch}` `{ch2}`（两位补零）占位符。

## 3. 交互规格

### 3.1 鼠标

| 操作 | 结果 |
|------|------|
| 单击源条目 | 选中该源（右栏显示属性），不播放 |
| 双击源条目 / 拖到空格 | 在空格开播；无空格时替换最久未活动的一格，并提示 |
| 格内单击 | 选中该格（右栏切到该格属性） |
| 格内双击 | 单画面放大（等价 `⛶`） |
| 格间拖拽 | 交换位置（两个源互换成各自新格，不断流） |
| 拖出格 | 停止该格并置空 |
| 右键格 | 菜单：全屏 / 静音 / 重新连接 / 复制地址 / 显示标注 / 关闭 |
| 悬停格 | 显示标题行操作按钮 |

### 3.2 键盘

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+N` | 添加源对话框 |
| `Ctrl+O` | 打开本地文件（临时源） |
| `Ctrl+L` | 聚焦地址输入框 |
| `Ctrl+S` | 保存当前布局为场景 |
| `Ctrl+1..4` | 布局 1×1 / 2×2 / 3×3 / 4×4 |
| `F11` | 整墙全屏 |
| `Esc` | 退出全屏 / 退出合流 |
| `M` | 当前选中格静音切换 |
| `R` | 当前选中格重连 |
| `←/→` | 全屏态下切换格（合流态下无效） |

### 3.3 状态视觉

| 状态 | 标题行状态点 | 信息条 | 备注 |
|------|--------------|--------|------|
| `Idle`（空槽） | 无 | 「双击添加」 | 虚线边框 |
| `Connecting` | 黄（呼吸） | 「连接中…」 | 显示已耗时 |
| `Buffering` | 黄 | 「缓冲 0.6s」 | 首帧前显示进度 |
| `Playing` | 绿 | 码率 / 分辨率 | 正常态 |
| `Stalled` | 橙 | 「卡顿 3s」 | 3s 无新帧触发；随后自动进 `Reconnecting` |
| `Reconnecting` | 橙（闪烁） | 「重连 2/5 · 4s 后」 | 可手动立即重连 |
| `Failed` | 红 | 分类原因（见 [video-wall.md](video-wall.md) §8） | 提供「重试」「编辑地址」 |
| `Stopped` | 灰 | 「已停止」 | 用户主动停止 |
| 软解回落 | 灰蓝小角标「软解」 | 解码信息显示 `sw` | 硬解失败时出现，不阻断播放 |

### 3.4 空状态与错误态

| 场景 | 文案与操作 |
|------|-----------|
| 无任何源 | 「还没有视频源。添加一个地址，或先试试本地文件。」+ [添加源] [打开文件] |
| 地址为空/非法 | 输入框下方红字：「无法识别的地址。示例：`rtsp://user:pass@192.168.1.64:554/…`」 |
| 认证失败 | 格内：「需要登录（401）。检查用户名/密码。」+ [编辑凭据] |
| 地址过期 | 「地址可能已过期（403）。HLS 签名地址通常有效期较短。」+ [刷新地址] |
| 不支持编码 | 「该编码不受支持：HEVC-10bit / DRM。」+ [查看支持列表]（打开 sources 文档的本地化副本或帮助页） |
| 超预算 | 顶部黄条：「当前布局超出本机解码预算（预计 CPU 92%）。建议改 2×2 或降低源分辨率。」+ [降级] [仍然继续] |
| 全部失败 | 顶部红条：「9 路均连接失败，检查网络或凭据。」+ [诊断]（逐格原因汇总） |

## 4. 布局规格（像素级约束，实现时按此对齐）

| 项 | 值 |
|----|-----|
| 格间距（gutter） | 4px（3×3 与 4×4 同值，保持密度一致） |
| 格内信息条高度 | 22px（小字号 11–12pt，等宽数字避免跳动） |
| 标题行高度 | 28px（状态点 8px 圆 + 名称 + 右侧按钮） |
| 画面最小可用尺寸 | ≥ 160×90；低于此值自动降为「只显示标题 + 状态」的紧凑格，不渲染画面 |
| 圆角 | 卡片 6px；画面区 0（避免裁切） |
| 视频面比例 | 默认 `Uniform`（留黑边），可选「拉伸填满」/「裁切填满」（每格独立） |
| 高 DPI | 所有尺寸按 DIP，图标用矢量；`PerMonitorV2` 感知，跨屏拖动不模糊 |
| 配色 | 沿用宿主主题变量（不新增品牌色）；状态色仅作点缀 |

```json
    }
```

```json
  "activeSceneId": "scene-default"

```

### 5.3 临时源 / 最近 `video-wall.recent.json`

```json
{
  "schemaVersion": 1,
  "items": [
    {
      "url": "https://example.com/course/live.m3u8?token=***",
      "protocol": "hls",
      "lastPlayedAt": "2026-11-13T09:40:00+08:00",
      "lastResult": "ok",
      "displayName": "直播课-周三"
    },
    {
      "url": "D:\\video\\demo.mkv",
      "protocol": "file",
      "lastPlayedAt": "2026-11-13T09:10:00+08:00",
      "lastResult": "unsupported-codec",
      "displayName": "demo.mkv"
    }
  ]
}
```

规则：

- `url` 落盘前**已脱敏**（`token/sign/key/auth` 值替换为 `***`）；重播时若检测到脱敏标记，提示「原地址含签名参数，可能需要重新获取」。
- `lastResult` 取 §3.3 的错误分类码，用于「最近」列表的角标。

### 5.4 凭据 `video-wall.credentials.bin`

```text
DPAPI 保护的结构（Windows）：{ "cred-01": { "user": "admin", "password": "<密文>" } }
```

- 只存引用（`credentialRef`），源条目本身不含账号密码。
- 导出源清单时 `credentialRef` 一并剔除。

### 5.5 内存态「格」（不落盘）

| 字段 | 类型 | 说明 |
|------|------|------|
| `index` | int | 0..rows*cols-1 |
| `sourceId` / `url` | string? | 绑定源；临时源直接存 URL |
| `state` | enum | 见 §3.3 |
| `stats` | record | 码率/分辨率/帧率/丢帧/缓冲/首帧/解码方式 |
| `player` | 句柄 | 后端对象，不进序列化 |

## 6. 原型迭代计划

| 迭代 | 目标 | 交付 | 验收人 |
|------|------|------|--------|
| W1（第 1 周） | 「能看」 | 单窗 1 格 + 地址粘贴 + 播放/停止 + 状态点 | 自己 |
| W2（第 2 周） | 「能排」 | 3×3 硬编码 9 路 + 空格 + 拖拽 + 单格全屏 | 自己 |
| W3（第 3 周） | 「能管」 | 源目录 + NVR 批量 + 场景保存/加载 + 属性栏 | 内部评审 |
| W4（第 4 周） | 「能合」 | 合流视图 + 音频策略 + 整墙全屏 | 内部评审 |
| W5+ | 打磨 | 空/错状态、快捷键、性能提示、暗色主题、高 DPI | 产品 |

原型期允许「假数据」：源目录可先用 9 条硬编码 `rtsp://` 回放地址（或本地文件循环播放）验证布局，不阻塞 UI 开发。

## 7. 原型阶段必须确认的 5 个决策（否则实现会返工）

| # | 决策点 | 建议 |
|---|--------|------|
| 1 | 视频面内是否允许叠控件 | **不允许**。控制条外置，角标在标题行（airspace 现实约束） |
| 2 | 合流是「另一个视图」还是「替换墙」 | **另一个视图**（可返回，墙上播放器不重建） |
| 3 | 空格替换策略 | 双击源时优先空格；无空格替换「最久未活动」的格并弹一次提示（可勾「不再提示」） |
| 4 | 临时源是否落最近列表 | **落**，但 URL 脱敏；签名地址重播要提示 |
| 5 | 场景是否含音频策略 | **含**（否则「值班室静音、会议独奏」每次都要重设） |

## 8. 与宿主 UI 的边界

| 归属 | 内容 |
|------|------|
| 宿主 `ToolWorkspace` | 页签容器、返回工具目录、关闭页签、主题变量、DPI |
| 宿主 `IToolUiHost` | 注册工作区工厂、弹对话框（添加源/批量导入/确认） |
| 工具 `Ui.Win` / `Ui.Desktop` | 上述线框的全部布局与控件、原生视频面嵌入 |
| 工具业务程序集 | 源模型、状态机、后端封装、场景读写；**不含任何 WPF/Avalonia 类型** |
| 主程序 | **不新增**任何视频墙专用 XAML/控件/文案键（遵守 [tools.md](tools.md) §5.2b「主程序不含工具业务 UI」） |
