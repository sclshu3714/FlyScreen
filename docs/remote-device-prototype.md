# 远程设备接入：原型设计（v1.8）

| 项 | 内容 |
|----|------|
| 性质 | 交互与页面原型设计；**不修改代码** |
| 本次修正 | 设备管理改为完整表格清单：本地设备加入布局后不再从列表消失；列改为设备名称 / 本地·远程·服务 / 地址 / 状态 / 操作 |
| 范围 | Windows 桌面（WPF）先做；远程设备不独立占槽；投影先做复制；支持自建中继 / 第三方 overlay |
| 非目标 | 官方中继、账号/付费、多地域、远程扩展投影、超过 4 台本地设备、手机作 Host |

---

## 0. 一句话逻辑

> **远程设备不是第 5 台设备，而是挂在某台本地电脑槽位上的一台“影子设备”。**
> 一台本地电脑可以绑多台远程，但每个槽位同一时间只展示、只投影其中一台；A、B 两台本地电脑可以各自展示/投影自己的远程，互不影响。

---

## 1. 核心模型

| 术语 | 含义 |
|------|------|
| 本地设备 | 已在电脑布局里占槽位的局域网电脑 / 手机 / 平板 |
| 远程设备 | 通过中继或 overlay 接入的电脑；**不单独占槽** |
| 绑定 | 远程设备挂到某台“已有本地设备”的槽位上 |
| 远程池 | 一台本地电脑下绑定的多台远程的集合 |
| 当前远程 | **每台本地电脑各自一个**；从自己的远程池中选一台显示 |
| 投影中 | **每台本地电脑各自一个**；当前远程投影到这台本地电脑 |

**硬规则：**

1. **每台远程只能绑定一台本地电脑**；不能一台远程绑多台本地电脑。
2. **一台本地电脑可以绑定多台远程**，形成远程池。
3. 每个槽位同一时间只显示 1 台远程；不同槽位可以各自显示 1 台。
4. 每个槽位同一时间只投影 1 台远程；不同槽位可以各自投影。
5. 远程只能绑定**已有本地设备**的槽位；空位不能绑。
6. 绑定键是 `LocalDeviceId`，不是槽位编号；本地设备换槽，远程池跟着走。
7. 布局网格、槽位数量、槽位位置永远不变；投影不触发重新布局。
8. 远程绑定不写入 `LayoutSync`，只存本机 `settings.json`。

## 2. 布局槽位

### 2.1 未绑定远程：普通槽位

```text
┌ 最左 ──────────────────────────────┐
│ ● 仅出站 ←                 [⋯]     │
│              🖥                    │
│         DESKTOP-KQPS38S           │
│           仅出站 ←                 │
└────────────────────────────────────┘
```

### 2.2 已绑定、未投影：本地主卡 + 远程条

```text
┌ 最左 ──────────────────────────────┐
│ ● 仅出站 ←                 [⋯]     │
│              🖥                    │
│         DESKTOP-KQPS38S           │
│           仅出站 ←                 │
├────────────────────────────────────┤
│ ● 已连接   [P2P]            [⋯]    │  ← 状态左上角；只有 ⋯
│   远程电脑名1                       │
│   绑定：最左 / DESKTOP-KQPS38S（小字）│
└────────────────────────────────────┘
```

- 远程条没有 `编辑 / 投影 / 删除` 按钮；
- 所有操作都在右上角 `⋯`；
- 状态在左上角，模式 `P2P` / `中转` 在状态旁；
- 底部小字显示绑定电脑。

### 2.3 投影中：远程主卡，本地缩成底部小字

```text
┌ 最左 ──────────────────────────────┐
│ ● 投影中   [中转]           [⋯]    │
│              🖥                    │
│          家里台式机                 │
│      鼠标跨屏进入：远程电脑          │
│  绑定主机：DESKTOP-KQPS38S（小字）   │
└────────────────────────────────────┘
```

- 远程替换**槽位内容**，但布局网格不变；
- 本地电脑缩成底部小字 `绑定主机：DESKTOP-KQPS38S`；
- 停止投影后，恢复 2.2 的“本地主卡 + 远程条”。

### 2.4 并行展示：A 显示远程1，B 显示远程2

```text
┌ 最左 / DESKTOP-KQPS38S ────────────┐   ┌ 中左 / MI 10 ──────────────────┐
│ ● 仅出站 ←                 [⋯]     │   │ ● 双向已连接              [⋯]   │
│         DESKTOP-KQPS38S           │   │         MI 10                  │
├────────────────────────────────────┤   ├────────────────────────────────┤
│ ● 已连接   [P2P]            [⋯]    │   │ ● 已连接   [中转]          [⋯]  │
│   远程电脑名1                       │   │   远程电脑名2                  │
│   绑定：最左 / DESKTOP…             │   │   绑定：中左 / MI 10           │
└────────────────────────────────────┘   └────────────────────────────────┘
```

- 每个槽位各自维护“当前远程”；
- A 的远程池只影响 A 槽位，B 的远程池只影响 B 槽位；
- 两个槽位可以同时展示、同时投影；
- 互不抢占“当前远程”。

### 2.5 远程池与 `⋯` 菜单

`⋯` 只列出**当前槽位这台本地电脑**的远程池：

```text
┌ ⋯ ───────────────────────────────────┐
│ 切换远程（本槽位远程池）                │
│  ● 远程电脑名1      P2P 38ms           │
│  ○ 远程电脑名2      中转 52ms           │
│  ○ 远程电脑名3      P2P 41ms           │
│ ──────────────────────────────────── │
│  编辑绑定（改绑到另一台本地电脑）        │
│  投影                                  │
│  删除                                  │
└──────────────────────────────────────┘
```

**规则：**

- 选中哪台，哪台成为**这个槽位**的当前远程；
- 其他槽位的当前远程不受影响；
- 当前槽位正在投影时禁止切换：提示“先停止本槽位投影，再切换远程”；
- 切换只改本槽位的显示和后台目标，不改布局。

### 2.6 编辑绑定：远程改绑另一台本地电脑

```text
┌ 编辑绑定 ──────────────────────────────────┐
│ 远程设备：家里台式机                         │
│ 当前绑定：最左 / DESKTOP-KQPS38S             │
│ 选择新的绑定电脑（单选）：                    │
│  ○ 最左   DESKTOP-KQPS38S                   │
│  ● 中左   MI 10                             │
│  ○ 中右   SCLSHU3714（本机）                 │
│  ○ 最右   空位（不可选）                     │
│                                            │
│ 说明：每台远程只能绑一台本地电脑；            │
│      改绑后加入目标电脑的远程池。             │
│ [ 取消 ]                       [ 确定 ]     │
└────────────────────────────────────────────┘
```

- 单选，不是多选；
- 改绑后，该远程从原本地电脑的远程池移到新本地电脑的远程池；
- 若它是原槽位的当前远程，原槽位自动选下一台或清空；新槽位若没有当前远程，它成为当前；若已有当前，它先作为池内备选；
- 若正在投影，先停止投影。

### 2.7 本地设备交换槽位

```text
交换前：最左 = DESKTOP-KQPS38S + 远程池 {A, B}，当前 A
交换后：中左 = DESKTOP-KQPS38S + 远程池 {A, B}，当前 A
```

- 远程池整体跟着本地设备走，不跟槽位 index；
- 当前远程属于哪个池，就跟着哪台本地设备走；
- 其他本地电脑的远程池不受影响。

**整卡拖拽规则：**

- 有远程绑定时，整个槽位是一张“整卡”：按住**上半本地卡**或**下半远程条空白处**拖拽，都是拖整张卡；
- 不能单独拖远程条；远程条不是独立拖拽对象；
- 远程条右上角 `⋯` 只开菜单，不触发拖拽；`⋯` 的点击区域优先于拖拽热区；
- 拖拽交换是原子操作：本地设备 + 整个远程池 + 当前远程一起交换，不存在“本地过去了、远程还在原槽”的中间状态；
- 投影中默认也允许整卡拖拽，投影会话跟着绑定的本地设备/远程走，不中断；如果后续觉得容易误操作，可加“投影中锁定布局”开关。

### 2.8 边界情况

| 情况 | 表现 |
|------|------|
| 本地设备被移除 | 它的整个远程池解除绑定；该槽位当前远程清空；其他槽位不受影响 |
| 当前绑定电脑离线 | 该远程条灰显；本槽位投影禁用；其他槽位不受影响 |
| 远程离线 | 该远程条灰显；投影禁用；可重连/删除 |
| 空槽位 | 不能绑定；编辑绑定里置灰 |
| 布局 4 台已满 | 不影响远程绑定；远程不占第 5 槽 |
| 当前远程投影中删除 | 先停止本槽位投影；删除后本槽位自动选下一台或回到仅本地 |

## 3. 后台逻辑：边缘目标切换

**布局不变，变的是鼠标跨屏进哪台电脑；每个槽位独立判断。**

| 状态（按槽位） | 槽位视觉 | 鼠标跨屏目标 |
|----------------|----------|----------------|
| 未绑定远程 | 本地主卡 | 本地电脑 |
| 已绑定、未投影 | 本地主卡 + 远程条 | **本地电脑** |
| 投影中，允许跨屏 | 远程主卡 + 本地小字 | **远程电脑** |
| 投影中，禁用跨屏 | 远程主卡 + 本地小字 | 本地电脑 |
| 远程离线 | 本地主卡 + 远程条灰 | 本地电脑 |

```text
SlotEdgeTarget(slot)
  if slot.ActiveRemote == slot.ProjectingRemote
     && 投影会话允许鼠标跨屏
  then Remote
  else Local
```

- 每个槽位独立计算；A 槽位进远程1，B 槽位进远程2，可以同时存在；
- 槽位位置、数量、邻接关系不变；
- 不触发 `LayoutSync` 重排；
- 边缘键鼠走现有 `EdgeDrag / EdgeMouse`，目标 peer 从本地设备换成远程设备；
- 远程端需启用输入接收（`ScreenExtendInput` / `InjectInput`）；
- 关闭“允许鼠标跨屏”后，即使投影中，该槽位边缘目标仍是本地电脑。

## 4. 网络页：连接配置 + 设备管理

### 4.1 连接配置（表格）

```text
┌ 连接配置 ──────────────────────────────────────────────────┐
│ [ + 添加配置 ]                                              │
│                                                            │
│  设备                 地址                          操作     │
│  ┌──────────────────┬────────────────────────────┬────────┐│
│  │ 本机网卡          │ [ 以太网 ▾ ]                │[刷新网卡]││
│  ├──────────────────┼────────────────────────────┼────────┤│
│  │ 远程设备/中转服务  │ [ wss://relay.example.com ] │[测试][删除]││
│  │                  │ ● 已连接 12ms                │        ││
│  ├──────────────────┼────────────────────────────┼────────┤│
│  │ 远程设备/中转服务  │ [ 100.64.0.2:15155 ]        │[测试][删除]││
│  │                  │ ○ 未连接                     │        ││
│  └──────────────────┴────────────────────────────┴────────┘│
└────────────────────────────────────────────────────────────┘
```

- 第一行固定：`本机网卡 / 网卡下拉 / 刷新网卡`；
- `添加配置` 增加一行：`远程设备/中转服务 / 地址 / 测试、删除`；
- 状态显示在地址格第二行，不新增列；
- 删除配置时，若有远程绑定，先提示“将解除绑定”；投影中先停止。

### 4.2 设备管理（完整设备清单，不再“加入后消失”）

> 设备管理是**全量清单**，不是“待添加列表”。本地设备加入布局后仍然保留，只把状态改成“已在布局：最左”，操作从“添加”变成“定位 / 从布局移除”。

```text
┌ 设备管理 ──────────────────────────────────────────────────────────┐
│ [ 刷新发现 ]   [全部] [本地] [远程] [服务]                            │
│ 刷新会同时刷新本地设备、远程设备、中转服务；                           │
│ 已在布局/已绑定的设备不会消失，只更新状态和操作。                      │
│                                                                     │
│  设备名称          本地/远程/服务  地址                  状态             操作 │
│  ┌────────────────┬──────────────┬──────────────────┬──────────────┬────────────┐│
│  │ DESKTOP-KQPS38S│ 本地          │ 10.10.1.18        │ 在线 · 已在布局：最左 │[定位][从布局移除]││
│  │ MI 10          │ 本地          │ 10.10.1.22        │ 在线 · 未加入布局     │[添加到布局]      ││
│  │ 手机 / 平板     │ 本地          │ 10.10.1.30        │ 在线 · 已在布局：中右 │[定位][从布局移除]││
│  │ 家里台式机      │ 远程          │ relay.example.com │ 在线 · 已绑定：最左   │[切换绑定][设为当前][删除]││
│  │ 远程电脑名2     │ 远程          │ 100.64.0.2:15155  │ 离线 · 已绑定：中左   │[切换绑定][删除]  ││
│  │ flyscreen-relay│ 服务          │ wss://relay...    │ 已连接 12ms           │[测试][编辑][删除]││
│  └────────────────┴──────────────┴──────────────────┴──────────────┴────────────┘│
└──────────────────────────────────────────────────────────────────────────────┘
```

**列定义：**

| 列 | 内容 |
|----|------|
| 设备名称 | 电脑名 / 手机名 / 服务名 |
| 本地/远程/服务 | 类型；`本地` 绿、`远程` 蓝、`服务` 橙 |
| 地址 | 本地 IP:端口 / 远程 endpoint / 中转服务 URL |
| 状态 | `在线/离线` + `未加入布局/已在布局：最左/已绑定：最左/已连接 12ms` |
| 操作 | 按类型和状态变化，见下 |

**操作规则：**

| 类型 / 状态 | 操作 |
|-------------|------|
| 本地 · 未加入布局 | `添加到布局`：选空槽（现有逻辑） |
| 本地 · 已在布局 | `定位`：跳到基础页并高亮槽位；`从布局移除`：只移除槽位，**不删除设备管理里的记录** |
| 远程 · 未绑定 | `绑定到布局`：打开 4.3 对话框 |
| 远程 · 已绑定 | `切换绑定`：改绑另一台本地电脑；`设为当前`：设为该槽位的当前远程；`删除`：删除远程记录 |
| 服务 · 已连接/未连接 | `测试` / `编辑` / `删除`；删除服务时，若有远程依赖，先提示解除绑定 |

**刷新规则：**

- 刷新发现同时刷新：UDP 本地设备 + 已配置远程设备 + 中转服务注册设备；
- 已在布局的本地设备保留在表里，只更新状态；
- 已绑定的远程保留在表里，只更新 `已绑定：最左` 和在线状态；
- 中转服务保留在表里，只更新 `已连接 / 未连接 / 延迟`；
- 过滤 `全部 / 本地 / 远程 / 服务` 只影响显示，不改变数据。

### 4.3 绑定到电脑布局（补齐的绑定步骤）

远程行点 `绑定` 后，**不直接跳布局**，先弹“选择本地电脑”对话框；绑定完成后再回布局查看。

```text
┌ 绑定到电脑布局 ────────────────────────────────────────────┐
│ 远程设备：家里台式机        [远程/中转]  ● 在线              │
│                                                            │
│ 选择要绑定的本地电脑（单选）：                               │
│  ┌──────────────────────────────────────────────────────┐ │
│  │ ○ 最左   DESKTOP-KQPS38S   在线   远程 2 台（当前：远程2）│ │
│  │ ○ 中左   MI 10             在线   远程 0 台             │ │
│  │ ○ 中右   SCLSHU3714（本机） 在线   远程 1 台（当前：远程1）│ │
│  │ ○ 最右   空位              —     不可选                 │ │
│  └──────────────────────────────────────────────────────┘ │
│                                                            │
│ 说明：远程设备不占新槽；绑定后加入该电脑的远程池。             │
│      该槽位没有当前远程时，这台自动成为当前；已有当前则先备选。│
│                                                            │
│ [ 取消 ]                              [ 绑定 ]             │
└────────────────────────────────────────────────────────────┘
```

**对话框规则：**

- 只列**已有本地设备**的槽位；空位显示“不可选”并置灰；
- 每行显示：槽位名、电脑名、在线状态、该电脑远程池数量、当前远程名；
- 单选；默认选中该远程“当前绑定”的槽位（如果是改绑）；
- 目标电脑离线也允许绑定（绑定是配置），但行内提示“离线，投影暂不可用”；
- 远程自身离线也允许绑定，绑定成功后远程条灰显，投影禁用；
- 确认按钮：首次绑定为 `绑定`，已绑定改绑为 `切换绑定`；
- 若该远程正在投影，先提示“先停止投影，再改绑”。

**绑定完成后的反馈：**

```text
已绑定到：最左 / DESKTOP-KQPS38S
当前显示：远程电脑名2（这台先加入远程池，点槽位 ⋯ 切换）
[ 去布局查看 ]
```

- 目标槽位没有当前远程 → 新绑的这台成为当前，立即显示远程条；
- 目标槽位已有当前远程 → 新绑的这台先进入远程池，不显示；提示用 `⋯` 或设备管理 `设为当前` 切换；
- `去布局查看` 跳到基础页并高亮目标槽位；
- 绑定关系立即写入本机配置，不需要点“应用”。

**空状态：**

```text
电脑布局里还没有本地电脑。
先到 基础 → 添加 一台局域网电脑，再回来绑定远程。
[ 去基础页添加 ]
```

## 5. 流程

### F1：远程绑定到布局

1. 网络 → 连接配置 → `添加配置` → 选 `中转服务`，填 `wss://relay.example.com` → `测试` 通过。
2. 网络 → 设备管理 → `刷新发现`，出现 `家里台式机`；已在布局的本地设备仍留在表里，只显示 `已在布局：最左`，不会消失。
3. 远程行点 `绑定` → 弹出「绑定到电脑布局」对话框。
4. 在对话框里选一台**已有本地设备**的槽位（如 `最左 / DESKTOP-KQPS38S`）；空位不可选。
5. 点 `绑定` → 提示“已绑定到 最左 / DESKTOP-KQPS38S”；可点 `去布局查看` 跳到基础页并高亮该槽位。
6. 这台远程加入该本地电脑的远程池：
   - 该槽位没有当前远程 → 它成为当前，立即显示远程条；
   - 该槽位已有当前远程 → 它先作为池内备选；点该槽位 `⋯` 切换，或在设备管理点 `设为当前`。
7. 若之后要改绑另一台本地电脑：设备管理行点 `切换绑定`，或槽位 `⋯` → `编辑绑定`，走同一个选择对话框。

### F2：投影

1. 当前远程条 `⋯` → `投影`。
2. 确认框：

```text
┌ 投影远程电脑 ──────────────────────────────┐
│ 家里台式机  →  最左 / DESKTOP-KQPS38S       │
│ 方式：复制    分辨率：720p    帧率：10       │
│ ☑ 允许鼠标跨屏进入远程                       │
│ 提示：绑定电脑需与本机在同一中继/overlay      │
│ [ 取消 ]                     [ 开始投影 ]   │
└────────────────────────────────────────────┘
```

3. 开始后：本槽位变远程主卡，本地缩成底部小字；布局网格不变；
4. 鼠标跨屏目标切到远程；停止后切回本地；
5. A、B 两个槽位可以各自执行 F2，互不影响。

### F3：切换远程 / 编辑绑定 / 删除

- `⋯` → `切换远程`：从本槽位远程池中选另一台为当前；本槽位投影中先停止；
- `⋯` → `编辑绑定`：把当前远程改绑到另一台本地电脑；投影中先停止；
- `⋯` → `删除`：删除当前远程；先停止本槽位投影；本槽位自动选下一台或回到仅本地；
- 以上操作只影响当前槽位，不影响其他槽位。

## 6. 状态机

```text
单个槽位：
  未绑定 → 已绑定（远程池，非当前） → 当前远程 → 投影中
                    ↑                      │
                    └──── 切换 ←───────────┘

投影中：空闲 → 协调绑定电脑 → 启动远程 Host → 投影中 → 停止 → 空闲
```

| 状态（按槽位） | 远程条 | 布局 |
|----------------|--------|------|
| 未绑定 | 不显示 | 本地 only |
| 已绑定非当前 | 不显示（在远程池） | 本地 only |
| 当前未投影 | 显示远程条 | 本地主卡 + 远程条 |
| 投影中 | 远程主卡 | 远程主卡 + 本地小字 |
| 离线/错误 | 灰显 | 本地主卡 + 远程条灰 |

## 7. 数据模型（设计层）

```text
LocalDevice
  Id: string
  Name: string
  RemoteBindings: RemoteBinding[]   // 远程池，可多台
  ActiveRemoteId: string | null     // 本槽位当前远程
  ProjectingRemoteId: string | null // 本槽位投影中远程

RemoteBinding
  RemoteId: string
  RemoteName: string
  BoundLocalDeviceId: string        // 只绑一台本地电脑
  Mode: P2P | Relay
  Endpoint: string
  State: Bound | Projecting | Offline | Error
  RttMs?: int
```

**规则：**

- 每台远程只有一个 `BoundLocalDeviceId`；
- 一台本地电脑的 `RemoteBindings` 可以有多条；
- `ActiveRemoteId` 是**每台本地电脑**一个，不是全局；
- `ProjectingRemoteId` 是**每台本地电脑**一个，不是全局；
- 本地设备被移除 → 它的 `RemoteBindings` 全部解除；其他设备不受影响；
- 远程绑定不写入 `LayoutSync`。

## 8. 接入点

| 模块 | 设计方向 |
|------|----------|
| `MainWindow` 网络页 | 本机网卡卡 → 连接配置表；局域网发现 → 设备管理 |
| `MainWindow` 布局页 | 槽位模板增加远程条；投影态切换为远程主卡 + 本地小字；网格不变 |
| `ConnectionManager` | 配置表驱动本机网卡、远程 endpoint、relay endpoint |
| `DiscoveryService` | 局域网 + 已配置远程 + 中继注册设备 |
| `ScreenExtend` | 每槽位远程 Host → 该槽位绑定电脑 Sink；按槽位返回 `SlotEdgeTarget` |
| `EdgeDrag/EdgeMouse` | 按槽位 `SlotEdgeTarget` 选择 peer；不重排布局 |
| `AppSettings` | 增加 `RemoteBindings`，按 `LocalDeviceId` 存远程池和当前远程 |
| `LayoutSync` | 不改；远程绑定是本机 UI/后台状态，不进协议 |
| `SecurityKey` | 中继房间用安全密钥派生，不做账号 |

## 10. MVP

**做：**

- 连接配置表格；
- 设备管理完整清单（本地 + 远程 + 服务；加入布局/绑定后不消失）；
- **一台本地电脑绑定多台远程**，形成远程池；
- **每个槽位各自一个当前远程**；A、B 可同时展示各自的远程；
- **每个槽位各自一个投影中远程**；A、B 可同时投影各自的远程；
- 槽位“本地主卡 + 远程条”；投影态“远程主卡 + 本地小字”；
- 投影中鼠标跨屏进入远程；停止后回本地；
- 编辑绑定（远程改绑另一台本地电脑）、删除、本地设备移除后的解绑；
- 自建中继部署指引。

**不做：**

- 一台远程绑多台本地电脑；
- 远程独立占第 5 槽；
- 同一槽位同时显示/投影多台远程；
- 远程扩展投影；
- 完整远程桌面窗口；
- 当前电脑转发远程帧到绑定电脑；
- 远程绑定同步到其他电脑布局。

## 11. 验收

1. 布局网格、槽位数量、位置在绑定/投影/停止过程中不变。
2. 远程条只有右上角 `⋯`，没有独立按钮；菜单含切换/编辑/投影/删除。
3. 一台本地电脑可绑多台远程；每台远程只绑一台本地电脑。
4. 每个槽位只显示一台远程；A 显示远程1、B 显示远程2 可同时成立。
5. 每个槽位只投影一台远程；A 投影远程1、B 投影远程2 可同时成立。
6. 未投影：鼠标跨屏进本地电脑；投影中：鼠标跨屏进远程电脑；停止后回本地。
7. 投影中本地电脑缩成底部小字 `绑定主机：...`，远程主卡仍在原槽位。
8. 远程改绑后，从原本地电脑远程池移到新池；原槽位自动选下一台或清空。
9. 有远程绑定时，按住上半本地卡或下半远程条空白处拖拽，整张卡一起移动；不能单独拖远程条；`⋯` 不触发拖拽。
10. 本地设备被移除时，只解除该设备的远程池；其他槽位不受影响。
11. 连接配置表第一行固定，添加行可选远程/中转，测试/删除可用。
12. 设备管理是完整清单：本地设备加入布局后仍保留，状态显示 `已在布局：最左`，操作变 `定位 / 从布局移除`；远程设备绑定后仍保留，状态显示 `已绑定：最左`；服务行也保留。
13. 设备管理远程行点 `绑定` 会弹出「绑定到电脑布局」对话框：只列已有本地设备的槽位，空位不可选；绑定后提示“已绑定到…”并可 `去布局查看`；已绑定行显示 `切换绑定`。

## 12. 待确认

1. **投影并发**：A、B 同时投影各自远程时，中继带宽和客户端资源是否接受？MVP 当前按“允许”，如果实测吃紧，可限制全局 1 路。
2. **投影中鼠标跨屏**：是否键盘也进入远程？当前只承诺鼠标跨屏。
3. **投影到非本机绑定电脑**：绑定电脑必须也在同一中继/overlay；否则 `投影` 置灰。若要当前电脑转发，单独立项。
4. **中继房间**：是否接受“同一安全密钥 = 同一中继房间”，不做账号。
